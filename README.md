Have problems managing expenses? Need help saving money?

Budget buddy can help you with that!


Budget Buddy is a budget and expense management platform based on Python. It gives you options 
to manage budget allocations, track expenses, and even gives you detailed visual
monthly overviews for your budget and expenses!

These overviews can help you track where you commonly overspend, your budget
category allocations, income breakdowns, and more. In turn, helping you effectively 
managw your budget!



How to initialize Budget Buddy:
1. Download this GitHub repository - on the right side of this repository, click
   the green "code" button, then download this repository as a .zip file then extract.
   
2. Run using Visual Studio Code - run with VSCode, make sure python is installed.

3. Set up Python virtual environent - At the bottom VSCode terminal, input "python3 -m venv BB"

4. Activate virtual environent - at the terminal, if you are using MacOS/Linux, input "source
    SP1/bin/activate". Otherwise, with Windows, use "Set-ExecutionPolicy -ExecutionPolicy RemoteSigned
   -Scope CurrentUser BB\Scripts\activate"

5. Install Matplotlib and Streamlit - at the terminal, input "pip install matplotlib streamlit"

Running Budget Buddy

After initializing, run the program through the terminal by inputting
"streamlit run main.py".
